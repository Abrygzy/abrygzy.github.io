This page gathers websites and tools that are useful in my daily work. The entries are grouped by topic so they are easier to browse and expand over time.

Astronomy

Frequently used astronomy databases, literature portals, and survey resources.

NASA ADS ↗

The standard literature search portal for astronomy and astrophysics papers.

arXiv Astrophysics ↗

Daily preprints across astrophysics, useful for tracking the latest papers.

SIMBAD ↗

Quick lookup for astronomical objects, identifiers, and bibliography links.

SDSS ↗

Survey portal for data releases, imaging, spectra, and project documentation.

Data and Analysis

Tools and services for datasets, notebooks, and reproducible research workflows.

Zenodo ↗

Repository for publishing datasets, software, and citable research outputs.

Overleaf ↗

Collaborative LaTeX editor for papers, notes, and presentations.

Jupyter ↗

Interactive notebook ecosystem for data exploration and analysis.

Astropy ↗

Core Python library ecosystem for astronomy data analysis.

Code hosting and version control platform for software and collaboration.

Lightweight whiteboard for sketches, flowcharts, and quick visual notes.
